# SpendSense Shared Contracts (`@arth/contracts`)

Shared TypeScript DTOs, exact BigInt integer-paise money utilities (`parseINRToPaise`, `parseNonNegativeINRToPaise`, `paiseToDecimal`, `formatPaiseToINR`), and `Asia/Kolkata` (`IST`) date-range helpers shared across SpendSense Web and SpendSense Backend.

> **Legacy Package Identifier:** `@arth/contracts` is preserved across all workspace imports and build scripts. **Maintainer:** Integration Lead (Ansh Gupta).

## Scripts
```bash
pnpm --filter @arth/contracts typecheck
pnpm --filter @arth/contracts build
```
