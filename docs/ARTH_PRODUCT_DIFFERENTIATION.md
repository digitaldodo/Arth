# Arth product differentiation

Arth's product direction is one coherent personal-finance record that favors accuracy, source traceability and user control over unreviewed automation.

## Highest-priority differentiators

1. **Cross-account reconciliation:** link related outflow/inflow pairs across user-owned accounts, card purchases and card payments without counting transfers as income/expense. Present rationale and confidence; only auto-link high-evidence pairs, and leave uncertain ones for review.
2. **Document-to-ledger-to-tax traceability:** retain source-document/page and verification provenance for extracted fields, then let the user explicitly match those fields to ledger entries and tax profile values. A bank credit is a candidate, never proof of taxable income.
3. **Explainable, versioned tax recommendations:** show the applicable Act/year/ruleset, calculation steps, verified inputs, assumptions, unavailable deductions, missing information and break-even calculation. Keep tax calculations deterministic and user-controlled.

## Guardrails

- Merchant category, transaction type and tax treatment are separate fields.
- Only explicit user confirmation can create learned merchant rules.
- PDF passwords and source documents stay client-side unless a user explicitly chooses a disclosed storage/processing option.
- An uncertain parser result stays out of the ledger until review.
- Product screens show unavailable/unsupported coverage plainly rather than filling gaps with sample financials.

## Measurement before claims

Measure parsing precision/recall per fixture and file format; balance discrepancy detection; precision of exact/possible reconciliation matches; duplicate false-positive rate; provenance completeness; tax rule fixture agreement; and document isolation/deletion behavior. Compare against a named competitor only with like-for-like fixtures and a published methodology.
